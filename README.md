## Instruções de compilação

Compilar e rodar:

```bash
gcc cinema.c pilha.c fila.c -o C-cinema
./C-cinema
```

Para debugar:

```bash
gcc cinema.c pilha.c fila.c -o C-cinema -g
gdb C-cinema
```

O arquivo binário C-cinema é excluído pelo .gitignore.
